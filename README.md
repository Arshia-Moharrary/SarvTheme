# Sarv Dental - Custom WordPress Theme

قالب اختصاصی وب‌سایت **Sarv Dental** (طراحی لبخند پرمیوم و دندانپزشکی زیبایی).

## 🛠 تکنولوژی‌های استفاده شده

- **WordPress:** نسخه 7.1.3
- **PHP:** نسخه 8.2 (با `declare(strict_types=1)` برای تایپ‌های سخت‌گیرانه)
- **Tailwind CSS:** نسخه 4 (رویکرد CSS-first و Logical Properties)
- **Vite:** به عنوان ابزار Build و توسعه (HMR)
- **Vanilla JS:** برای تعاملات فرانت‌اند

## 📂 ساختار پوشه‌ها

```text
sarv/
├── dist/                  # خروجی Build (توسط Vite تولید می‌شود - در Git نیست)
├── src/                   # فایل‌های منبع
│   ├── css/
│   │   ├── app.css        # فایل اصلی Tailwind و تعریف توکن‌ها (Design System)
│   │   └── fonts.css      # تعریف @font-face
│   ├── fonts/             # فایل‌های فونت (Peyda & Satoshi)
│   └── js/
│       └── main.js        # نقطه ورود جاوااسکریپت
├── .gitignore
├── functions.php          # راه‌اندازی قالب، بارگذاری Vite، فیلترهای RTL
├── header.php             # هدر HTML و تگ‌های Meta
├── footer.php             # فوتر و بسته شدن تگ‌ها
├── index.php              # تمپلیت پیش‌فرض (Fallback)
├── style.css              # متادیتای قالب (شناسنامه وردپرس)
├── package.json           # وابستگی‌های Node.js و اسکریپت‌ها
└── vite.config.js         # تنظیمات Vite
```


## 🚀 راه‌اندازی محیط توسعه

- **۱. در مسیر قالب (wp-content/themes/sarv) وارد شوید.**
- **۲. وابستگی‌ها را نصب کنید:**
```bash
npm install
```
- **۳. فایل‌های فونت را در src/fonts/peyda/ و src/fonts/satoshi/ قرار دهید (طبق ساختار موجود).**
- **۴. سرور توسعه را اجرا کنید:**

```bash
npm run dev
```
(سایت با HMR بارگذاری می‌شود و تغییرات بدون رفرش اعمال می‌شوند).

## 📦 ساخت نسخه Production (استقرار)
برای ایجاد فایل‌های نهایی و بهینه‌شده (مینیفای شده با هش یکتا):

```bash
npm run build
```
پس از اجرای این دستور، پوشه dist ایجاد می‌شود. کدهای PHP در functions.php به طور خودکار تشخیص می‌دهند که باید فایل‌های Production را از روی manifest.json بارگذاری کنند.

## 🎨 سیستم طراحی (Design System)
تمام توکن‌های طراحی درون src/css/app.css در بلوک @theme تعریف شده‌اند. هیچ‌گاه مقادیر رنگ یا سایز را به صورت مستقیم (Hardcode) در کلاس‌های Tailwind استفاده نکنید. همیشه از توکن‌ها استفاده کنید:

### رنگ‌ها
```bg-deep-emerald``` / ```text-deep-emerald (#0E3B32)```

```bg-warm-ivory``` / ```text-warm-ivory (#F6F3EC)```

```bg-champagne-gold``` / ```text-champagne-gold (#C8A56A)```

```bg-forest-noir```, ```bg-charcoal```, ```bg-soft-stone```

### تایپوگرافی (فونت پیش‌فرض: Peyda برای فارسی، Satoshi برای لاتین)
- ```text-hero``` (64px)

- ```text-h1``` (48px)

- ```text-h2``` (36px)

- ```text-h3``` (26px)

- ```text-body```-range (20px)

- ```text-body``` (16px)

- ```text-caption``` (12px)

- کلاس‌های اختصاصی فونت: ```font-peyda```, ```font-satoshi```

### شعاع گوشه‌ها
- ```rounded-brand``` (12px)

- ```rounded-brand-lg``` (24px)

## 🌐 پشتیبانی از RTL
جهت‌نویسی درون ```functions.php``` به صورت قطعی روی ```dir="rtl"``` و ```lang="fa-IR"``` تنظیم شده است. در طراحی UI، همیشه از کلاس‌های Logical (مانند ```ms-*```، ```me-*```، ```ps-*```، ```pe-*```، ```start-*```، ```end-*```) به جای کلاس‌های فیزیکی (```ml-*```، ```mr-*``` و ...) استفاده کنید.

### 🧪 روش آزمایش و تأیید موفقیت (گام ۵)

برای اطمینان از صحت این گام:

1. **بررسی فرانت‌اند:**
   - سرور Vite (`npm run dev`) را اجرا کنید.
   - صفحه اصلی سایت را باز کنید. باید یک گرید کارت‌های تمیز (حتی اگر مطلب تستی داشته باشید) با رنگ‌های برند مشاهده کنید. اگر مطلبی ندارید، پیام "محتوایی یافت نشد" را با استایل مناسب ببینید.
   - بررسی کنید که فونت‌ها و رنگ‌ها در این اسکلت جدید به درستی اعمال شده باشند.

2. **بررسی Production (تست نهایی):**
   - ترمینال را ببندید و دستور `npm run build` را اجرا کنید.
   - سایت را رفرش کنید. باید بدون هیچ خطایی و با فایل‌های هش‌دار (Hashed) از پوشه `dist` کار کند.
   - فایل `README.md` را باز کنید و صحت محتوای آن را بررسی کنید.

3. **بررسی کدها:**
   - مطمئن شوید که در `index.php` از کلاس‌های فیزیکی (مثل `ml-4` یا `pr-6`) استفاده نشده و همه‌چیز با کلاس‌های Logical (مثل `ms-2`، `pt-4`) نوشته شده است.
